About CORS and permissions

Quill talks to Ollama from its background service worker, never from the web page you are on. That avoids mixed-content and page-CSP problems (for example https:// sites reaching http://localhost).

Ollama refuses browser requests that carry an unfamiliar Origin. Quill removes that header from its own requests to the address above, so you don't need to set OLLAMA_ORIGINS. For a non-local address, the browser asks you to allow Quill to reach that one host when you press Save & test.

Still seeing a 403 error?

Allow extension origins on the server, then restart Ollama:

Windows (PowerShell)

setx OLLAMA_ORIGINS "chrome-extension://*"

macOS

launchctl setenv OLLAMA_ORIGINS "chrome-extension://*"

Linux (systemd): sudo systemctl edit ollama and add

[Service]
Environment="OLLAMA_ORIGINS=chrome-extension://*"

Reaching Ollama from another machine also needs OLLAMA_HOST=0.0.0.0 on the server.
